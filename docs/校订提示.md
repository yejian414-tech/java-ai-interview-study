## 已核验示例：Q043，PDF 第 55 页

原题以“成员内部类不能定义静态成员”为前提，回答也未限定 Java 版本。

这一限制不能套用到所有 Java 版本。Java SE 16 之前，内部类不能声明静态初始化器，静态成员也仅限常量变量；从 Java SE 16 起放宽。Java SE 17 语言规范明确允许内部类声明静态成员和静态初始化器。

官方依据：[Java SE 17 JLS §8.1.3](https://docs.oracle.com/javase/specs/jls/se17/html/jls-8.html#jls-8.1.3)。核验日期：2026-11-09。

学习时应把题目改成：“内部类声明静态成员的规则如何随 Java 版本变化？”
