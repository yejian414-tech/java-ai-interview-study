# Java + AI Agent 学习手册

将 Java 与 AI Agent 面试资料整理成可在电脑、手机浏览器访问的学习网站。

支持 800 道题、82 个主题、随机出题、全文搜索、相关题返回、阅读/自测切换、个人笔记、收藏、重点标记与集中查看，以及学习记录导入导出。

## 网站入口

GitHub Pages 发布目录为 `main` 分支的 `/docs`。

在线访问：<https://yejian414-tech.github.io/java-ai-interview-study/>。

## 手机使用

用手机浏览器打开网站，可以添加到主屏幕。所有阅读功能直接在浏览器中运行，不需要 API Key。

重点、收藏、笔记、自测回答和布局偏好保存在当前浏览器，不会提交到仓库。电脑与手机间转移记录时，在“设置与资料”中导出 JSON，再到另一台设备导入。浏览器清理站点数据后，本地记录会消失，请按需备份。

电脑端可从左上角整体隐藏主导航；全部题目、分类、搜索和重点列表仍与正文并排显示，题目列表保持原有宽度，正文利用新增空间展开，标题、列表及阅读文字自动放大。再点同一按钮可恢复目录。随机出题继续单题阅读；手机保留目录抽屉及“题目列表 / 正在阅读”切换。分类目录沿用点击模块后展开其主题的方式。模块宽度与目录收起状态会自动保存；可在“设置与资料”中恢复默认布局。

“随机出题”可选择全部知识模块或指定模块，也可只抽重点题。同一轮按随机顺序出题、不重复；点击“换一题”继续，抽完后可开始新一轮。每道新题默认先隐藏答案，可以记录回答后再展开原文。随机顺序、当前位置和自测回答会保存在本浏览器。

标为重点的题目以暖黄色底色和边框突出显示，侧边栏“重点”集中收录这些题目。

旧版待复习标记会转入重点；已有笔记、收藏和自测回答继续保留，旧版已理解记录在备份数据中保留。

## 本地预览与构建

需要 Python 3.9+，构建只使用标准库。

```sh
python scripts/build.py
python -m http.server 8765 --directory docs
```

打开 <http://localhost:8765/>。

## 更新内容

- `src/`：界面模板、样式与交互代码。
- `data/questions.json`：题目、原文回答、页码和关联。
- `data/taxonomy.json`：学习分类。
- `data/learning-units.json`：首轮学习路线。
- `docs/`：发布产物、导图和参考 PDF。

修改源文件后运行 `python scripts/build.py`，提交生成的 `docs/index.html` 并推送到 `main`；GitHub Pages 根据该目录自动发布。

## 资料与校订

题库依据《2026年java+AiAgent面试题汇总》整理。原始回答未逐条技术核验；已确认的校订独立显示，历史实现与框架 API 应结合技术版本学习。PDF 位于 `docs/assets/source.pdf`，网站中的页码链接支持在线打开。
